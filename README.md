# Piccolo-AX
Piccolo [AX] — A deterministic, &lt; 300 MB bare-metal Linux console appliance built on Batocera Linux to keep proven PC hardware out of landfills. Features a real-time 6.12-rt kernel, locked core isolation, Intel iGPU offloading, VRAM protection, and crackle-free USB DAC audio for AX emulators.
